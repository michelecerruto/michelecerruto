## What I do

I run **M2C**, a one-person AI-assisted studio built around a single thesis:
*good developers shipping with AI tools can deliver in days what teams used to deliver in months,
without losing review discipline.*

Inside M2C, a custom CRM converts client briefs into pull requests, sprint by sprint —
backed by a Turborepo monorepo of five apps, a pgvector RAG engine, background job processing,
and a hard rule that no AI-generated diff lands without a human review.

Alongside M2C I work on **investigative intelligence software at Octostar**.

## How I work

I treat AI as a tool inside a structured pipeline, not a substitute for development judgment.
The pipeline:

```
Think       Claude.ai           Architecture, trade-offs, plan — no code yet
Write       Claude Code         Tight scoped diffs in the terminal
Review      Cursor              Git diffs only, read-only by rule
Ship        GitHub Actions      Tests, types, lint, deploy
```

Composition over inheritance, pure functions when sensible, typed contracts at every boundary,
tests where they earn their keep. I read diffs more carefully than most read prose.
